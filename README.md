# Ever After

From guest list to last dance. Ever After is a wedding planner for Windows: guests and replies, budget and suppliers, the planning timeline, the wedding party, seating and place cards, letters and invitations, music, an ideas board, the day-of schedule, and gifts and thank-yous.

## Install

Download **Ever After Setup x.y.z.exe** from the [latest release](../../releases/latest) and run it.

Windows may say "Windows protected your PC" the first time, because the installer isn't code-signed. Click **More info**, then **Run anyway**.

## Updates

Once it's installed, Ever After updates itself. New versions download in the background and install when you restart the app. You can see what's new, or check straight away, in **Settings → Updates**.

## Your data

Your wedding is saved in a file on your computer, in the folder you choose, and is never uploaded anywhere by Ever After. Backups are kept alongside it. See the [privacy policy](PRIVACY.md) for the details, including how the optional Pinterest and Spotify connections work.
