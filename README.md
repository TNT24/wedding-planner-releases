# Wedding Planner

Plan every detail of the day: guests, budget and suppliers, the planning timeline, the wedding party, seating and place cards, the day-of schedule, and gifts and thank-yous.

## Install

Download **Wedding Planner Setup x.y.z.exe** from the [latest release](../../releases/latest) and run it.

Windows may say "Windows protected your PC" the first time, because the installer isn't code-signed. Click **More info**, then **Run anyway**.

## Updates

Once it's installed, Wedding Planner updates itself. New versions download in the background and install when you restart the app. You can see what's new, or check straight away, in **Settings → Updates**.

Your wedding files stay wherever you save them, and are never uploaded anywhere.
